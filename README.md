# Restful-Booker-API-testing
Testing a hotel reservation booking testing using API testing 
## How to Use
1. Download the `.json` file from this repository.
2. Open Postman.
3. Go to **File > Import** and select the `.json` file.
4. Use the imported collection to test the API.
